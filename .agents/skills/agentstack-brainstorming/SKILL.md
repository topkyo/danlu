# AgentStack Brainstorming

Use for L3 ambiguity, design choices, UI/API behavior, architecture changes, or when the user asks to discuss first.

Steps:

1. Explore only enough context to ask good questions.
2. Ask concise clarifying questions when needed.
3. Present 2-3 approaches only when there is a real choice.
4. Recommend one approach and explain tradeoffs.
5. Produce a brief design with scope, non-goals, risks, and verify strategy.
6. Hand off to `agentstack-write-plan` only when the implementation is multi-file or multi-step.

Do not force this flow for one-line fixes or clear bugfixes.
