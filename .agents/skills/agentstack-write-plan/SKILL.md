# AgentStack Write Plan

Use after requirements are clear.

Plan format:

```markdown
# <Task> Plan

## Goal
- ...

## Scope
- In:
- Out:

## Files
| File | Action | Reason |
| --- | --- | --- |

## Tasks
- [ ] Task 1: ...
- [ ] Task 2: ...

## Verify
- Targeted:
- Full:

## Risks
- ...
```

Each task should be executable and verifiable. Skip this flow for small single-file work.
