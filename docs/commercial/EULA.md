> **状态**：草案，待正式法律审阅。在正式 EULA 生效前，本文是当前书面流程指针：如何取得商业许可、许可覆盖什么、不覆盖什么。正式签署以双方签字的书面协议为准。

## 1. 双许可背景

炼丹炉（`aiwiki`）采用双重许可：

| 路径 | 条款 | 适用 |
|------|------|------|
| **开源** | 仓库 `LICENSE` 中的 AGPL-3.0 | 未签署商业许可的默认路径；须遵守 copyleft 等义务 |
| **商业** | 单独签署的商业许可协议 | 在许可范围内免除 AGPL copyleft 义务 |

未持有生效商业许可前，必须按 AGPL-3.0 使用本软件。

## 2. 许可范围

本商业许可面向：

- **产品形态**：Desktop Obsidian + 本地 `aiwiki` runtime（local-first，用户自托管）
- **用户规模**：单人或小团队（具体座位数/组织范围以书面协议为准）
- **部署**：被许可方自有设备与 vault；不包含托管 SaaS

## 3. 商业许可授予什么

在协议有效期内、约定范围内，商业许可通常授予：

1. **AGPL copyleft 豁免**：可为约定用途闭源/商业使用本软件，而无须按 AGPL 公开衍生作品源码（以书面协议条文为准）。
2. **约定席位内的安装与使用**：在 Desktop Obsidian + 本地 runtime 上运行炼丹炉。
3. **协议载明的支持等级**：如 Personal / Pro 邮件支持或陪跑服务（见 `docs/commercial/SUPPORT.md`、`PRICING.md`）。

具体权利以双方签字协议为准；本文不构成已生效授权。

## 4. 商业许可不授予什么

商业许可**不**包含（亦不得据此宣称）：

|--------|------|
| **SaaS / 托管运营权** | 不得将本软件作为面向第三方的托管服务对外运营 |
| **再分发为竞品** | 不得将本软件（或其实质部分）再包装为独立竞品对外销售或分发 |
| **投资建议 / 投顾** | 不构成 buy/sell/hold、仓位、择时或任何投资建议 |
| **自动交易 / 信号服务** | 不授予交易所连接、交易信号生成或金融执行相关权利 |
