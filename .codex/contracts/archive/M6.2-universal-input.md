# M6.2 Universal Input

## Goal

把炼丹炉的"输入端"从多入口（AskBox / DropZone / drop-url / drop-pdf / drop-image / drop-repo / drop-note / ask）收敛成**单一用户心智入口**：

- Product Shell 首屏默认只暴露一个 Universal Input 组件
- CLI 提供 `aiwiki drop <anything>` 与 `aiwiki drop -` 单一 deterministic dispatcher
- 路由规则纯 syntax / extension / prefix / metadata，**不调 LLM、不联网探测 content-type**
- 现有 typed `aiwiki drop url ...` / `drop-url` / `ask` 等命令零删除、零行为变化

## Non-Goals

- 不引入 `aiwiki <input>` 顶层 dispatcher（破坏现有 argparse compatibility）
- 不引入 LLM 判别 / content-type 探测 / URL fetch 触发 routing
- 不改 raw/wiki/output 分层、不改 receipt / audit / ShellSummary schema
- 不删 Advanced 入口、不删 typed subcommand、不删 legacy top-level 命令
- 不做 M6.3 Single Today Feed 的输出端收敛（独立 milestone）

## Approach (chosen: C-lite)

Product Shell 与 CLI 共享同一 deterministic input contract：

### Router

新增 `src/aiwiki/input_router.py`（单文件，pure-function classifier，无 IO 副作用）：

```
classify_universal_input(value: str) -> UniversalRoute
```

`UniversalRoute` 枚举（匹配现有 typed subcommand）：
- `url` — `^https?://`
- `pdf` — `.pdf` 后缀（local path 或 URL path）
- `image` — `.png/.jpg/.jpeg/.gif/.webp/.svg` 后缀
- `repo` — `git@`, `ssh://`, `.git` 后缀, 或本地 git 目录
- `note` — `note:` 前缀 或 多行文本（含 `\n`）
- `ask` — `ask:` 前缀, 含 `?`, 或其他 plain-text 默认（**ambiguity policy: default to ask**）

路由规则按上述顺序逐条匹配；首条命中即返回。歧义 plain text 默认走 `ask`（保留首屏 AskBox 的历史心智）。

### CLI

新增 `aiwiki drop <payload>` bare 形态（payload 不是已知 typed subcommand 时走 router）：

- `aiwiki drop https://example.com` 等价于 `aiwiki drop url https://example.com`
- `aiwiki drop ./x.pdf` → `drop pdf ./x.pdf`
- `aiwiki drop ./x.png` → `drop image ./x.png`
- `aiwiki drop git@github.com:user/repo.git` → `drop repo ...`
- `aiwiki drop "note: meeting note"` → `drop note ...`
- `aiwiki drop "what is X?"` → `ask "what is X?"`
- `aiwiki drop -` 从 stdin 读取 payload 后路由

保留：`aiwiki drop url ...` / `drop pdf ...` / `drop image ...` / `drop repo ...` / `drop note ...` / `drop-url` / `drop-pdf` / `drop-image` / `drop-repo` / `drop-note` / `ask`。

### Product Shell

- `render.js`：新增 `renderUniversalInput(plugin, container)`，替换 `renderAskBox` + `renderDropZone` 作为首屏默认主路径
- `plugin.js`：新增 `runUniversalInputCommand(value)` 方法，调 router（client-side mirror 或 CLI 桥接）后 dispatch 到对应现有 handler
- AskBox / DropZone 旧组件函数保留（不删），但首屏默认不再调用；移到 Advanced 抽屉或 secondary 区域
- placeholder：`Drop URL, PDF, image, repo, note, or question...`
- 拖拽文件仍可用，归入同一 Universal Input 区域

## Verification

### Python 单元

`tests/test_input_router.py`：
- URL → url
- PDF (path / URL with .pdf) → pdf
- 各类 image 后缀 → image
- git URL / `.git` 路径 / 本地 .git 目录 → repo
- `note:` prefix / 多行文本 → note
- 含 `?` / `ask:` prefix / plain text → ask
- Ambiguity policy 断言：bare plain text → ask

### CLI 集成

`tests/test_cli.py`（扩展现有）：
- `aiwiki drop https://example.com` 与 `aiwiki drop url https://example.com` 触发同一 handler，stdout/JSON contract byte-equal
- 各 typed bare drop 等价对照 ≥ 5 组
- `aiwiki drop -` 读 stdin
- 现有 `aiwiki drop url ...` / `aiwiki drop-url` / `aiwiki ask` 行为零变化（regression guard）

### Acceptance

`tests/fixtures/acceptance/M6.2/case_universal_input/` + `tests/test_acceptance_loop.py::test_universal_input_routing`：
- 单 case 跑 5 个 bare drop 输入（url/pdf/image/note/ask），断言每个产生与 typed 等价的 receipt / state diff
- 不依赖 LLM / 网络（pdf/image 用本地 fixture 文件，url 用 file:// 或 stub）
- 加入 `scripts/run_acceptance.sh`

### Product Shell 契约

无 byte-freeze。新增 `tests/test_product_shell_universal_input.py` 或扩 `tests/test_product_shell.py`（基于 string contract）：
- built `main.js` 包含 `renderUniversalInput` / `runUniversalInputCommand`
- placeholder 字符串包含 `URL` / `PDF` / `image` / `repo` / `note` / `question` 关键词
- `Universal` / `universal-input` 至少 1 处出现（语义 marker）
- 旧 AskBox/DropZone 函数仍存在（regression guard，不强制首屏调用）

构建验证：
- `bash .obsidian/plugins/furnace-product-shell/build.sh` pass
- `node --check .obsidian/plugins/furnace-product-shell/main.js` pass

### 全套验证

- `bash scripts/verify.sh` pass
- `bash scripts/run_acceptance.sh -v` 全 acceptance pass（M6.1 5 + M6.1b 4 + M6.2 1 = 10）
- src/ coverage 不退步（baseline `src/aiwiki/cli.py` 90%）

## Stop Lines

任一触发即停 contract、回滚到 batch 起点：

- Router 调用任何 LLM / 网络 / 子进程探测 content-type
- 改 receipt / audit / ShellSummary / planner-log / signal schema
- 删除任何 typed subcommand / 顶层 legacy 命令 / Advanced 入口
- 引入第三方 Python / npm 依赖
- M6.1 / M6.1b acceptance 任一回归
- 顶层 `aiwiki <input>` dispatcher

## Batches

每 batch < 600 LOC，独立 commit，verify 通过后再进入下一 batch。

### B1 — Router 实现 + 单元测试

- 新增 `src/aiwiki/input_router.py`（pure function，~150 LOC）
- 新增 `tests/test_input_router.py`（覆盖 6 类路由 + ambiguity policy + edge cases）
- 不改 CLI / Shell
- Verify: `verify.sh` pass + 覆盖率不退

### B2 — CLI bare drop dispatcher

- `src/aiwiki/cli.py`：`drop` parser 接受 bare payload（preserve 现有 typed subparsers as known kw-args）
- `aiwiki drop -` stdin 路由
- 扩 `tests/test_cli.py`（≥ 6 个 bare drop equivalence + stdin + legacy regression）
- Verify: `verify.sh` pass + cli.py 覆盖率不退

### B3 — Product Shell Universal Input

- `.obsidian/plugins/furnace-product-shell/src/render.js`：新增 `renderUniversalInput`，首屏默认调用之
- `.obsidian/plugins/furnace-product-shell/src/plugin.js`：新增 `runUniversalInputCommand`
- `.obsidian/plugins/furnace-product-shell/styles.css`：universal-input 容器样式（最小可用）
- 旧 `renderAskBox` / `renderDropZone` 函数保留（不调用，不删）
- Build: `build.sh` pass / `node --check main.js` pass

### B4 — Acceptance + 契约 + 收口

- `tests/fixtures/acceptance/M6.2/case_universal_input/` + `tests/test_acceptance_loop.py::test_universal_input_routing`

- `scripts/run_acceptance.sh` 自动跑 M6.2
