# AgentStack Finish

Use this when implementation is complete.

Required final summary:

- Changes.
- Verification command and result.
- Review status.
- Risks.
- Follow-ups.

For high-risk tasks or when the user asks for artifacts, run:

```bash
scripts/agentstack-finish
```
