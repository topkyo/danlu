# Vault README

This is the minimal openable vault fixture for `demos/investing-demo-pack/`.

## Structure

- `raw/inbox/` - fictional redacted input notes.
- `wiki/sources/` - source pages with frontmatter and provenance.
- `wiki/judgments/` - thesis judgment with v1 and v2 review trail.
- `wiki/elixirs/` - candidate reusable investing judgment asset.
- `output/reports/` - openable demo report.
- `output/control/execution-receipts/` - redacted demo receipts.

## Demo material types

1. Company-cycle material: `raw/inbox/company-cycle-v1.md`
2. Industry and competition material: `raw/inbox/industry-competition-v1.md`
3. Counter-evidence risk material: `raw/inbox/counter-risk-v2.md`

All content is synthetic and redacted for demonstration.
